# Персонализатор СКБ — Telegram Mini App

Команда 13 · Rizz Banking · кейс-школа Альфа-Будущее «Персонализация коммуникаций с корпоративными клиентами».

> **Прототип Proof of Concept.** Все компании, люди, суммы и события — синтетические. Продукт не является сервисом
> Альфа-Банка и не подключён к его системам: ML-оптимизатор, CRM и email работают через явно обозначенные mock-адаптеры.

## Что решает

Оптимизатор банка знает, **что** предложить, но не учитывает, **кому, когда и как** — до сделки доходит 1 клиент из 200.
Персонализатор — слой поверх текущего оптимизатора (архитектура не перестраивается):

`ML-скор (AS IS) → фильтры (отказы, лимиты, 152-ФЗ) → что и когда (отрасль, сезон, события) → кому (роль ЛПР, группа) → как (канал и частота по активности) → действие (NBA)`

Движок перенесён из вашего прототипа (`index.html`) на сервер без изменения логики: **паритет проверен на 5 004 профилях,
0 расхождений** (фикстура и тест в `backend/tests`).

## Что внутри

**Telegram Mini App** (React, открывается кнопкой в боте), интерфейс зависит от роли:

| Роль | Экраны |
|---|---|
| Клиент — ЛПР компании | Главная с персональным предложением под роль («почему я это вижу», «не интересно»), адаптивный путь «Витрина → Расчёт → Заявка», мои заявки (поиск, фильтры, сортировка), карточка заявки (история, переписка, отмена, ответ на уточнение), уведомления, профиль (отказы от коммуникаций, настройки уведомлений, Telegram) |
| Клиентский менеджер | Главная с KPI, задачи от правил (звонок за 48 ч, уточнить роль в CRM, «клиент сомневается»), заявки портфеля со сменой статусов и внутренними комментариями, карточка клиента |
| Аналитик СКБ | Метрики пилота A/B (CR, CTR, Time to Action, просмотр→сделка, отписки, z-тест, UX-метрики пути), **симулятор «меняем профиль — меняется результат»**, план касаний для группы, клиенты с «что если», запуск кампании |

**Адаптивный путь** — сигналы считает сервер: быстрый клиент → «Оформить сразу»; ≥2 возврата на витрину → «Коротко» и
сравнение; ≥3 пересчёта или пауза → подсказка (сохранить, сравнить, спросить менеджера; бухгалтеру — «отправить ФД»);
уход с формы → черновик и «Продолжить» на главной. Не больше одной подсказки за сессию.

**Telegram-бот** (aiogram 3): `/start` с привязкой аккаунта или демо-ролью, кнопка Mini App в меню, push-предложения с
кнопками «Рассчитать / Не интересно / Отписаться», статусы заявок, задачи КМ с «Взять в работу / Выполнено» (диалог через
состояния), защита от повторной обработки update, outbox-доставка уведомлений с повторами.

**Backend** (FastAPI): около 60 эндпоинтов, роли и доступ к данным только своей организации или портфеля, кампании с лимитами
частоты и «стоп-краном», версии бизнес-правил, аудит, идемпотентность.

## Архитектура

```
Telegram ──► Бот (aiogram) ─┐
     │ кнопка Mini App      │ общий сервисный слой и БД
     ▼                      ▼
Mini App (React) ──HTTPS──► FastAPI /api ──► движок персонализации (чистые функции)
                              │                └─ policy (лимиты), journey (триггеры), holding (группа)
                              ├─► PostgreSQL / SQLite (SQLAlchemy 2, Alembic)
                              ├─► outbox уведомлений → Telegram Bot API
                              └─► адаптеры: оптимизатор (mock/HTTP), email (mock), CRM (данные в БД)
```

Подробно — [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md): модель данных, права, потоки, A/B.

## Быстрый старт

### Вариант 1. Docker (PostgreSQL)

```bash
cp .env.example .env
```

Задайте в `.env` как минимум `POSTGRES_PASSWORD`, затем:

```bash
docker compose up --build
```

Откройте http://localhost:8000/miniapp (браузерный режим) и http://localhost:8000/api/docs (OpenAPI).

### Вариант 2. Локально без Docker (SQLite)

Нужны Python 3.12+ (проверено на 3.14) и Node.js 22+ (проверено на 24). Windows:

```bash
powershell -ExecutionPolicy Bypass -File scripts/run-local.ps1
```

macOS / Linux:

```bash
sh scripts/run-local.sh
```

Скрипт создаёт окружение, ставит зависимости, собирает Mini App, применяет миграции, заполняет демо-данные и запускает
сервер на http://127.0.0.1:8000. Пересоздать демо-данные: флаг `-Reset` / `--reset`.

> Windows: если проект лежит в очень длинном пути, бинарные модули Python не загружаются (ограничение MAX_PATH).
> Скрипт поэтому создаёт окружение в `%USERPROFILE%\.venvs\personalizer`.

### Режим разработки фронтенда

```bash
cd frontend && npm run dev
```

Vite на :5173 проксирует `/api` на backend :8000.

## Подключение Telegram

1. В [@BotFather](https://t.me/BotFather): `/newbot` → получите токен.
2. Нужен публичный **HTTPS**-адрес (Telegram открывает Mini App только по HTTPS):
   - для показа с ноутбука — туннель: `cloudflared tunnel --url http://localhost:8000` (выдаст `https://…trycloudflare.com`);
   - на сервере — домен + `docker compose --profile https up -d` (Caddy получит сертификат Let's Encrypt).
3. В `.env`: `TELEGRAM_BOT_TOKEN=…`, `PUBLIC_BASE_URL=https://ваш-адрес`, `TELEGRAM_MODE=polling` (локально) или
   `webhook` + `TELEGRAM_WEBHOOK_SECRET=…` (сервер). Если api.telegram.org недоступен из вашей сети — `TELEGRAM_PROXY`.
4. Перезапустите сервер. При старте бот сам выставит команды и кнопку меню «Приложение» → `{PUBLIC_BASE_URL}/miniapp`.
5. Напишите боту `/start`. В демо-режиме выберите роль; иначе откройте приложение и войдите — Telegram привяжется после
   проверки подписи initData. Привязка из браузера: Профиль → «Подключить Telegram» (одноразовая ссылка `t.me/<бот>?start=<код>`, 15 минут).
6. Необязательно: `/newapp` в BotFather — прямая ссылка `t.me/<бот>/<app>?startapp=app_12` откроет заявку №12 (`task_5`, `offer_7` — тоже).

Проверка: `GET /api/health` показывает `telegram.running`, адрес Mini App и режим.

## Безопасность

- Mini App: на сервер уходит только исходная строка `initData`; сервер проверяет HMAC-подпись (ключ из токена бота) и
  срок `auth_date`, пользователя берёт только из проверенных данных. `initDataUnsafe` не используется для входа.
- Права проверяются на сервере для каждой записи: клиент видит только свою организацию, менеджер — свой портфель,
  чужой ID отвечает 404. Внутренние комментарии клиенту не отдаются.
- Пароли — argon2; сессии — случайные токены, в БД хранится только SHA-256; cookie `httpOnly` + CSRF (double submit);
  в Mini App — Bearer-токен с коротким сроком.
- Ограничение частоты запросов и попыток входа, вебхук Telegram с секретом, CSP с `frame-ancestors` только для Telegram,
  журнал аудита без паролей и токенов, идемпотентность создания заявок и комментариев.
- Персональные данные: роль ЛПР хранится как должность, без ФИО (152-ФЗ); все данные синтетические.

## Развёртывание на сервере

Бесплатно и без своего сервера — Render.com по `render.yaml`: пошагово в [docs/DEPLOY_RENDER.md](docs/DEPLOY_RENDER.md).

На своём VPS:

1. Сервер с Docker, домен с A-записью, открытые 80/443.
2. Создайте `.env` из примера. Задайте `ENVIRONMENT=production`, `COOKIE_SECURE=true`, `TELEGRAM_MODE=webhook`,
   `PUBLIC_BASE_URL=https://домен`, `DOMAIN=домен`, секреты. Для показа кейса `DEMO_MODE=true`, для боевого контура — `false`.
3. Запустите:

   ```bash
   docker compose --profile https up -d --build
   ```

4. Миграции применяются при старте контейнера; демо-данные заполняются, если `SEED_DEMO=true` и БД пустая.

## Известные ограничения

- Реальных интеграций с Альфа-Банком нет: склонность к продукту — синтетические значения из версии правил (mock-адаптер
  с HTTP-контрактом), email — mock-outbox, «Альфа-Босс» и баннер ИБ показаны плейсментами в Mini App, push — сообщения бота.
- Аналитика A/B считается по синтетической истории в масштабе гипотез команды (CTR +15%, CR +20–25%); это демонстрация
  расчёта, а не результат пилота. Значимость на синтетике не достигается — так и показывается.
- Rate limit и состояния диалога бота хранятся в памяти одного процесса; для нескольких инстансов нужен Redis.
  Запускайте один воркер (иначе несколько копий polling).
- Веб-кабинет для сотрудников на десктопе отложен по решению команды: все роли работают в Mini App, полный API есть в `/api/docs`
  (правила, админка, аудит — пока только через API).
- Связь с api.telegram.org в среде разработки была недоступна, поэтому бот проверен автотестами с подменой Bot API,
  а не в живом Telegram. Для живой проверки нужен токен и HTTPS-адрес (раздел «Подключение Telegram»).
- Шрифт Styrene взят из брендбука кейс-школы; не публикуйте репозиторий открыто вместе со шрифтом.
