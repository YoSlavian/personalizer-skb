# Демонстрация экспертам (5 минут)

Перед показом: сервер запущен, демо-данные свежие.

```bash
cd backend && python -m app.seed --reset
```

Удобно держать два устройства: телефон с Telegram (клиент) и второй аккаунт или браузер (менеджер, аналитик).
Все данные синтетические — скажите об этом в начале.

## 1. Проблема и решение (30 с)

«Оптимизатор знает, что предложить, но не кому, когда и как: 1 сделка из 200 просмотров. Мы добавили признаки
и правила поверх текущего оптимизатора — ничего не перестраиваем».

## 2. Меняем профиль — меняется результат (1,5 мин) — роль «Аналитик»

1. Вкладка **Симулятор**, пресет **A · Агрохолдинг**: оборотный кредит «Ликвидность к сезону закупок», адресат — ФД головной
   компании (3 юрлица = 1 получатель), Email + Альфа-Босс.
2. Пресет **B · IT-компания**: бухгалтеру — «Интеграция с учётной системой», баннер ИБ + push, маршрутизация: кредит уходит ЛПР.
3. Пресет **C · Логистика**: роли нет в CRM → нейтральный текст, канал — менеджер, задача КМ уточнить роль.
4. Пресет **D · Импортёр**: валютный платёж → событийное правило, плейсмент рядом с «Валютным переводом».
5. Включите «Отказ от всех коммуникаций» → «Ничего не отправляем». Покажите вкладку **Результат**: «было / стало» и
   таблицу коэффициентов «почему именно это». Вкладка **Группа** — план касаний: одно сообщение группе в неделю.

## 3. Клиент в Telegram (1,5 мин) — роль «Клиент: ФД агрохолдинга»

1. Главная: персональное предложение с визуалом оборотов по месяцам («5 нед. до пика»), «Почему я это вижу».
2. «Рассчитать лимит» → витрина → калькулятор. Нажмите «Пересчитать» сразу — появится «Оформить сразу»
   (быстрый клиент). Ещё два пересчёта — подсказка «Сомневаетесь?» → «Спросить менеджера».
3. «Оформить заявку» → MainButton «Отправить заявку» → номер заявки и время до заявки.
   (Под ролью бухгалтера та же подсказка предлагает «Отправить расчёт финдиректору».)

## 4. Менеджер и статусы (1 мин) — роль «Клиентский менеджер»

1. Главная: задача «Клиент сомневается в расчёте» — пришла из пути клиента; в Telegram — уведомление с кнопками.
2. Заявки → новая заявка → «Взять на рассмотрение» → «Одобрить» с комментарием.
3. У клиента: уведомление в боте и в разделе «Уведомления», история статусов в карточке заявки.

## 5. Эффект и пилот (30 с) — роль «Аналитик», вкладка «Пилот»

CR и CTR тест против AS IS, Time to Action, отписки, сообщения на группу, UX-метрики адаптивного пути, z-тест
(«пока не значимо — нужен пилот»). Кампания: предпросмотр → запуск → повторный запуск показывает, как лимиты частоты
останавливают лишние сообщения. План: 9 месяцев, гипотезы по ICE H2 → H3 → H4 → H1.

## Если что-то пошло не так

- Нет интернета в зале: Mini App работает в браузере (`/miniapp`) с демо-входом; бот без сети не ответит.
- Сменить роль в Telegram: Профиль → «Сменить демо-роль».
- Данные «испорчены» прогонами: `python -m app.seed --reset`.
